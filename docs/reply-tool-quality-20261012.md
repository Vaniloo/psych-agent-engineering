## 优先顺序

1. 明确询问已有记录时优先确保记忆工具可用并执行；多字段问题分别检查覆盖，避免只答其中一项。
2. 返回证据不足时表述“这次检索未找到相关内容”，禁止推断“你从没说过”；后续窄化缺失字段检索应受次数、耗时限制。
3. 报告工具统一正式报告和近期概览的可用性字段，最终回复先回答是否有可看内容，再简短说明依据。
4. 调整回复措辞和长度约束，保留正反馈但避免解释用户未表达的心理动机。
