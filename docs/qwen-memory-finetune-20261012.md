完成一轮 BF16 LoRA 微调，本地开发环境已采用 **原始 Qwen3-Reranker 0.6B 重排 + 微调 Qwen 4B Memory 判断**。Router v5 / Executor v6 保持 Laya；原 Memory v8 服务与私有配置备份保留，可回滚。当前是本地实验性替换，未发布生产版本、提交或推送 Git。

后续已在相同权重上接入批量判断、近期原话扩展和轻量兜底，完整检索中位约 364 ms；本文保留最初训练及串行接入记录，最新运行边界与验证见 [批量检索与兜底记录](qwen-memory-serving-20261012.md)。

## 训练与数据

基座固定为 Qwen/Qwen3-Reranker-4B，revision `22e683669bc0f0bd69640a1354a6d0aebcfeede5`，4,021,784,576 参数。冻结基座，以 LoRA r16/alpha32/dropout 0.05 训练 attention/MLP 投影的 33,030,144 参数。覆盖相关性、充分性、事件、事实、偏好、方法及时间需求七项判断。使用一次前向 yes/no logits，不训练自由文本生成。

2,882 条决策样本仅遍历一次：micro batch 4、累积 4、181 次更新、AdamW、LR 1e-4、seed 1412。按任务/类别加权，不重复采样稀少正例。纯优化 223.3 秒；优化及随后校准/评测约 267.5 秒，不包括加载与准备。训练峰值分配约 8,706 MiB。

从既有 pair-round7-final 和 sufficiency-round8 课程构建，排除未复核/teacher_draft，不调用教师 API。train/calibration/validation/test 为 2,882/832/852/919 条决策。删除人工记录时间和跟踪字段，保留实际事件日期、数量与来源；按声明事件组和规范化输入合并关联组件，跨 split 优先 test、validation、calibration、train，冲突标签和挑战输入/组件排除。旧源文件未重写。

标签是项目/程序策略，没有独立人工或临床复核，语义模板仍共享，稀少偏好/方法正例仍较少。不是实际用户错误率。

## 接口与原文检索验证

实际 HTTP 为 **300/311 原始正确、300 正确接受、9 错误接受、2 弃权**。Laya 同题参考为 239 原始正确、228 正确接受、68 错误接受、15 弃权。单项 HTTP 中位约 50.7 ms，包含本地/SSH，非并发压测。

原生批次与单条 HTTP 在 qwen-fresh-pair-19-no 存在一项 BF16 近边界类别差异，该项没有被接受；保留记录，不据此修改模型。剩余错误主要涉及少量关系方向、他人经历相关性和事件标签漏判。事件分类正确数与 Laya 持平，不能宣称全面解决。

调用真实 0.6B/4B 服务和临时合成索引验证：本人宠物原话召回、助手建议不成为本人证据、无法消解的散步时长冲突返回 controlled、owner 隔离、原始 ID 保留/不重复；无凭据接口返回 401。验证未调用回复生成或新增用户对话/目标/进度，不代表全部自然对话、知识库、负载或临床效果验收。

0.6B 固定原始 revision `e61197ed45024b0ed8a2d74b80b4d909f1255473` 和权重摘要，未微调。只返回完整候选排列，Runtime 校验范围、完整性及有限分数，不接受新原文或 ID，不按低分删除记录。故障保留原顺序。启用重排时收集两个批次再判断充分性，保留后批修正/冲突机会；若交付条数截掉已检查证据，降为 controlled。

## 本地实验链路与回滚

### 补充：完整检索对照与延迟

随后在运行模型前冻结 12 个新编写场景，每场景 8 条用户原文、分属两个合成会话；四臂使用同一来源记录与查询。严格通过条件为交付所有必需证据、无额外无关证据、充分性判断符合预先标签。包含本人/他人、明确修正、未解决冲突、缺字段、跨会话合并、收发方向、语义改写、否定偏好、实际方法、全无关候选。是作者定义的开发场景，数量小，不是独立用户准确率；不用于训练、调阈值或选择权重。

| 链路 | 严格通过 / 12 | 对预标信息不足场景误判充分 | 检索中位 / P95 |
| --- | ---: | ---: | --- |
| BM25 + Laya v8 | 2 | 3 | 433 / 863 ms（12 次） |
| BM25 + 原始 0.6B 重排 + Laya v8 | 0 | 2 | 809 / 1,019 ms（12 次） |
| BM25 + 微调 4B | 5 | 0 | 1,022 / 1,090 ms（12 次） |
| BM25 + 原始 0.6B 重排 + 微调 4B | 5 | 0 | 1,031 / 1,221 ms（36 次） |

严格通过对额外无关原文敏感，0.6B 重排臂会检查全部八条，原始臂可能早停，不能将 0/12 简化为重排模型正确率。0.6B 仅改变顺序，本轮未证明它进一步改善 4B 的最终证据质量。四臂都保留来源身份；都有 1 个语义改写问题因 BM25 未选中必需原文而失败，重排或判断模型无法恢复未进入候选池的记录。

4B 在纠正、未解决冲突、本人宠物、否定偏好、全无关池五类严格通过。仍有项目日期/预算及跨会话字段漏召回、未记录时长的显式事实漏判、姐妹骑车时长被认为与本人相关、操作方法及邮件发送方向混入他人证据。偏保守的充分性减少了错误充分，但会留下本可以回答的问题。311 项单点成绩没有覆盖这些表达，因此保留失败结果，不据此宣称真实记忆准确率达到 96.5%。

补测 30 次同一短候选的串行暖机 HTTP 判断，中位 **70.4 ms**、P95 **117.6 ms**，与此前 311 项各类判断的中位 50.7 ms 不同。当前完整链路中位 **1.03 秒**、P95 **1.22 秒**，包括本地索引、0.6B、逐条 4B 判断及 SSH 往返，不含回复生成；不是并发负载或长历史测试。八条相关性当前按顺序发起请求，后续性能优化可优先考虑有限批量推理，保留相同来源与接受规则。

冻结输入、摘要、每条交付证据及延迟位于本会话 outputs 的 `retrieval-cases.json`、`retrieval-manifest.json`、`retrieval-ablation.json`。没有额外训练、教师 API 调用或用户业务数据写入。

**BM25/近期候选 → 原始 Qwen 0.6B 重排 → Qwen 4B+LoRA 相关性/充分性 → 现有回复生成。** 后台四类观察也使用 4B，原话写入不依赖标签，分类漏判不会删除记录。

独立 worker 在 lab 回环 18094/18095，使用本项目 SSH 转发。启动校验基座版本、权重、适配器与 renderer。运行指标返回 qwen provider、实际模型名及“实验接入”。前端代理 → Java → Runtime 指标接口返回 200，Memory 为 `psych-memory-qwen4b-lora-20261012`，7/7 启用，重排开启；另两角色 ready。旧 Laya v8 的 18092 未停止。

回滚配置仅在私有 `work/qwen-memory-before-20261012.env`；恢复为 dev-stack.env 后重启本项目 Runtime。服务凭据不进入 Git、样本或报告。接入依据用户允许一定错误率的试用范围，未改写历史严格发布门槛或 rejected 判定，不是生产认证。
