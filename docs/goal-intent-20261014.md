# 目标同义表达与指代修复 · 2026-10-14

上一轮命名目标读取修复没有覆盖“看一下我完成了什么目标”和“那把这个设成新目标吧”。本轮补齐目标列表查询、上下文指代以及原始授权与生成规划之间的连接。

## 实际行为

- 查询目标不再要求“我的目标”或完整标题。已完成列表由SQL按拥有者和状态筛选，不会因最近50条进行中目标挤占列表而消失。列表请求不会误继承会话先前的某个具体目标。
- “设成”“加入”“存成”等创建表达进入同一创建流程。对指代和较少见的表达，使用已有生成服务解析最近8条同会话对话，输出有界目标意图和内容；普通明确创建命令仍直接使用原本的本地决策路径。
- 明确唯一的内容转成规范表达供目标Qwen模型判断。当前原话、请求ID和账号身份继续由应用控制；解析器不能向写入工具指定目标ID、步骤或进度。
- 后端从拥有者对应的同一会话重新读取原始上下文，并结合当前已保存的创建命令进行结构化规划。历史助手回复只可解释用户现在明确接受的建议，不能自行授权保存；当前处理中回复不作为目标来源。
- 两个候选没有明确选择时先问清楚，不新建。否定保存、他人引用、仅讨论和模型/服务故障均不强行创建；不放松Qwen判断阈值。

这不是新的训练轮次。语义解析是有界的生成辅助，不取代Router、Executor、Memory或后端拥有者/事务校验；只在相关创建表达中增加调用，20秒超时后澄清。后续仍应扩充独立同义表达评测，不能把几条页面复现解释为全面意图准确率。
