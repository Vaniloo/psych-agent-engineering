# 主链路整理 · 2026-10-14

目标是让项目只有一套可解释的线上执行链路，并让阅读入口描述当前实现。本轮同时发布此前已完成的 loop、跨会话证据、知识语料、模型适配和工具可视化工作，未重新训练权重。

## 代码

- 删除未被图使用的 `_after_planner` 分支调度。
- 删除 Runtime `_execute_tools` 与 ToolController.run 兼容循环；生产只运行 decide / execute / observe 图节点，离线只读探针复用这些节点。
- Planner 删除未使用的生成客户端参数、compact 序列化方法与伪异步风险检查。风险来自本轮路由结果；缺失时显式 unknown，保留既有保守回退。
- `graph.py` 负责请求编排；`response.py` 负责证据与生成；`response_prompt.py` 负责回答规则；`goal_operations.py` 负责受控目标操作。
- 移除保存后目标 preamble，以及与当前写入顺序冲突的 prompt。只有真实回执支持时才确认目标/进度保存。
- 合并重复忽略项和 Compose 公共依赖配置；补齐当前目标 worker、记忆契约/重排/时区、loop 与入口容量变量的传递。

本轮未删除业务权限、失败兜底、旧数据读取兼容及训练回归脚本。训练目录不参与 Runtime 启动；历史实验的价值是解释候选为何接受或拒绝，已补上独立导航，避免与当前线上路径混淆。
