# 0.6B事实性门控专项试验

完成一轮独立0.6B LoRA微调，未接入正式写入、未替换4B Memory，也未增加在线模型worker。结果支持继续研究轻量门控，但仍有误接受，不能单独授权长期记忆写入。

## 自然对话发现的问题

10条不含“记住/别记住”指令的表述，加6次跨会话追问，暴露了以下边界：

- 普通偏好、通勤习惯和周末活动可以自动保留；临时情绪、同事经历及假设通常被跳过。
- “家里那只猫叫奶糖”缺少显式第一人称，没有形成长期候选，但可从近期原话召回。自然通勤变化进入复核，旧事实未替代；回答仍能结合近期原话说出骑车十来分钟。音乐变化新增条目，没有完成替代。
- “我是不是已经养成每天早起的习惯了？”被误写成活跃事实，并进入召回依据。失败记录原样保留；后来没有以清理后的数据冒充通过。

用户要求语义门控后，临时扩充的疑问句规则已撤掉，没有部署。新任务只判断候选是否包含用户对自身现实处境、经历、偏好或感受的事实陈述，不判断长期保留价值，不核实客观真伪。整轮有一条自述，也不意味着同轮的问题或假设可以一起当事实写入；混合句仍需要正确候选边界及后续来源核对。

## 基座和训练

使用官方[Qwen3-0.6B](https://huggingface.co/Qwen/Qwen3-0.6B)，固定版本`c1899de289a04d12100db370d81485cdf75e47ca`，与当前重排器是不同模型。英文、中文短提示和基础输出校验均显示明显yes偏置，因此没有直接启用原生权重。

| 设置 | 本轮 |
| --- | --- |
| 训练 / 校准 / 验证 / 测试 | 1,932 / 480 / 480 / 960条，事实族隔离 |
| LoRA | rank 8、alpha 16、dropout 0.05、学习率1e-4 |
| 优化 | 1 epoch、121次更新，只训练yes/no两种token得分 |
| 阈值 | 仅校准集选择temperature=0.5，放行阈值0.8 |
| 耗时 / 显存 | 优化36.07秒，含评测59.81秒；训练峰值4,729MiB |

数据均为合成和自编，没有私人聊天或教师API调用。分区共享模板，960题满分不能外推真实表现。另外使用31条自然开发题和训练前冻结的32条新编自然题，不参与梯度或阈值选择；它们也不是独立人工金标。原32条开发题中的一条存在标注歧义，已排除，原始结果和修订说明保留。

## 结果

| 检查 | 原生0.6B | 微调后原始二分类 |
| --- | --- | --- |
| 自然开发题 | 16/31 | 28/31 |
| 新编自然题 | 16/32 | 30/32 |
| 同模板、事实族隔离测试 | 480/960 | 960/960 |

校准阈值挡住一条低裕量疑问句，但两个自然集合仍各有2条误接受：一般建议“每天早起可能会更有精神”、虚构经历“故事里的我每天六点起床”、无问号求建议“下班后我最适合做什么来放松”、他人状况“我妈最近总是睡不好”。门控共放行36条，其中4条错误；31条负例仍有4条被误接受，不能只看总体正确率。

只读复核这4条时，现有4B的`write_worthy + grounded`挡住3条，仍错误放行求建议那条。这不是完整链路评测，也不是同任务专训4B的公平规模对照。

从磁盘重新加载adapter后，新编32题仍30/32。31次热请求模型计算P50约33.08ms、P95约41.12ms，推理峰值1,225.8MiB；不含HTTP、排队或完整聊天，未重新压测。

## 当前取舍和复现

0.6B专项训练明显有效，但本轮仍只保留实验候选。正式4B继续负责保留价值、来源和新旧关系。若后续比较4B，应训练相同事实性任务、使用相同分区和误接受指标，而非直接比较不同任务头。
