## 第一步：第十轮下降的来源

| --- | ---: | ---: | ---: | ---: |
| Router | 84 | 87 | 44 | 46 |
| Executor | 108 | 113 | 57 | 96 |

第十轮新权重导致分数与置信度分布退化；Router 原始答对总数不变，不能据此断言所有语义判断能力变差，也不能仅凭这个对照证明任务干扰。旧权重换新校准虽增加覆盖，也把整条错误接受数分别从 28 提高到 35、从 28 提高到 37，因此校准替换没有直接接入。

方法为历史服务概率的逆温度重建，1e-30 截断尾部不可恢复。原策略概率回环误差小于 1e-9，原接受状态逐项精确重现；交换策略结果是数值重放，不是新的原生推理或临床评测。

## 第二至四步：只训练需要优化的任务

- Executor 仅训练 goal_action / goal_outcome，工具选择、创建目标的判断保留。
- Memory 仅训练旧分类与时间需求五项，既有 relevance 与 evidence_sufficient 的参数、策略和结果保留。五项在一个隔离组内共享参数，尚未进一步逐项隔离。

新增 TaskParameterAdapter 使用一份独立的完整参数副本，**不是 LoRA，也不是单独训练头**。先以原模型预测完整问题批次，再用适配参数预测同一批次，仅替换归属任务的答案，在 finally 中恢复原参数。这样避免拆问题改变未训练任务的上下文。文件路径、架构、基本权重与适配权重哈希均检查。代价是额外显存和重复推理，不能把隔离实验延迟当成线上负载成绩。

## 结果与拒绝原因

历史 444 条加另外编写、训练前冻结的 41 条新案例（Router 14、Executor 15、Memory 12），合计 485 条。实际审核包含本轮在内的历史 split，精确输入重合零；源不完整旧输入单独记载。精确隔离不等于语义独立。

| 角色 | 原始答对：旧→候选 | 可用正确：旧→候选 | 整条错误接受：旧→候选 | 弃权：旧→候选 |
| --- | ---: | ---: | ---: | ---: |
| Router | 107→108 / 160 | 90→82 | 32→23 | 38→55 |
| Executor | 125→134 / 175 | 118→109 | 30→9 | 27→57 |
| Memory | 116→118 / 150 | 108→100 | 33→24 | 9→26 |

可用正确要求整条所有标注任务答对且被接受；关键错误另外逐项检查，不能被同条其他任务弃权遮蔽。

- 风险分级原始答对 127/159→128/159，可用正确 113→103，错误接受 14→5。收益较小，危机与来源归属仍有错误。
- 目标匹配原始答对 95/129→108/129，错误接受 19→4，但可用正确 85→72；目标状态原始答对 90/123→97/123。分类有提升，自动同步有效覆盖下降，Python 应用检查未匹配数 21→32。
- Memory 的 semantic 原始答对 13/22→16/22，preference 18/20→16/20。在 readiness-0216 新增关键 preference 接受错误。episodic 原始答对保持 12/15，可用正确 12→4。相关性及证据充分性保持原样，既有充分性错误没有解决。

三个候选均不满足各评测组覆盖不退步、严格覆盖改善、关键接受错误为零的门槛。Memory 另不满足无新增关键错误。候选与原始训练产物均标记 rejected，保留供分析，没有部署。训练均自然完成，拒绝接入不是训练或推理失败。
