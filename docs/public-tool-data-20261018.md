ToolACE有248条真正的空工具列表，保留用于后续研究工具不可用情况，但没有自行追加no-tool标签。518条使用其他工具声明格式，保留原文并标记目录未解析；另有1条记录在目录已解析时仍有调用解析问题。某些未解析目录记录也包含调用问题，问题出现次数不能直接相加当作记录数。

APIGen-MT不少`arguments`是JSON编码字符串，已在机械视图中解码并记录，原始消息不变。最终199条记录含378次目录中找不到对应声明的调用，保留并隔离，未凭名称生成缺失schema。此前解析器将JSON字符串参数也算异常，已修正，统计以`interchange-v3`为准。

APIGen-MT完整多轮轨迹有助于研究基于工具观察继续行动，但仅有3种目录、26个不同工具名，不能单靠5,000条轨迹宣称具备广泛未见工具泛化。ToolACE也有大量没有紧随工具观察的调用标注，不能把它们当已验证执行轨迹。

## 来源与许可分开管理

主来源为[ToolACE](https://huggingface.co/datasets/Team-ACE/ToolACE)，Apache-2.0。APIGen-MT以[作者仓库](https://huggingface.co/datasets/Salesforce/APIGen-MT-5k)声明的CC-BY-NC-4.0单独保留作非商业研究支线，不默认进入拟商用模型训练。固定revision与可重复命令见[导入说明](../agent-runtime/training/public_tools/README.md)。

原始数据与全部转换产物位于：

```text
/home/ubuntu/data/psych-agent-routing-20261009/datasets/public-tools-official-20261018/
  manifest.json
  raw/toolace/
  raw/apigen_mt/
  interchange-v3/
    toolace.jsonl
    apigen_mt.jsonl
    *-issues.jsonl
    audit.json
    verification.json
```

v1/v2只保留转换器调试历史，不作为最新数据入口。原始大文件留在data盘，本地outputs仅保存清单及审计/核验结果。

## 校验结果与下一步约束

21项测试通过，覆盖复杂参数名、嵌套字面量、不可执行的恶意调用文本、空目录与未知目录区分、JSON字符串参数、缺失工具声明、禁止猜补标签及整条导入来源校验。服务器完成全部16,300条原文与消息逐条比对、文件hash和索引覆盖核验，全部通过。

现有`toolgen_v2`训练器要求完整候选排序、绝对适用度与finish/clarify模式，官方数据未直接提供。下一步先适配监督接口，保留动态工具描述和候选评分思路；只使用数据真实提供的监督，不把所有未选工具当负例、不把任意文字回复当结束、不把缺失schema调用当正确候选。训练前再完成来源分支、去重、工具隔离切分和小规模验证。
