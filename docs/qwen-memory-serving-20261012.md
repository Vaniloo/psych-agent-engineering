# Qwen Memory 批量检索与轻量兜底 · 2026-10-12

本地开发应用已接入同一轮微调 4B 的新版服务，未增加训练轮次，未调用教师或回复生成 API。Router v5 / Executor v6 保持 Laya，原始 0.6B 权重与 4B LoRA 摘要不变。运行指标已显示 Qwen、批量判断及近期原话补充召回。

## 改动

1. **批量相关性判断**：Qwen worker 新增 `/v1/decisions/batch`，一项任务最多 16 个独立输入。保留原 renderer、来源、概率验证和接受规则，返回位置索引供客户端核对。实际检索最多 12 条候选，一次相关性批次后单独判断证据充分性；不再逐条发起 HTTP 请求。旧单条接口继续用于后台分类与充分性。老 worker 不支持批量接口时，只在 404/405 下回退到同一受校验单条接口；鉴权、超时及错误概率不触发兼容降级。
2. **有界语义补充**：原有 BM25 最多 8 条候选，与同一拥有者最近最多 24 条用户原话合并去重。原始 0.6B 对最多 32 条原文排序，GPU 每批 8 条；保留所有原始词面候选，最多补入 4 条词面检索漏掉的候选，再交给 4B。没有新增 embedding 服务或全历史向量索引。近期窗口以外的语义漏召回仍可能发生，不能宣称全量语义召回。
3. **人物边界**：自我范围问题中，排除明确只描述他人的原话，例如“我妹妹每次游泳二十分钟”。问题本身涉及家人/朋友、他人对用户的行动，以及混合本人和他人事实，继续由模型判断。不做完整实体解析、收发方向解析或任意人名推断。该规则不改写、删除持久原文。
4. **临界分数弃权**：首版批量 BF16 推理暴露了一项额外错误接受。温度 0.25 能把小原始 logit 间隔放大成高概率；新版以原始 yes/no 间隔不足 2 logits 时弃权，额外开销只是数值检查。温度、训练阈值、权重和训练报告保持不变，服务返回 `abstentionReason=small_raw_logit_margin`。这是开发阶段的数值稳定性启发式，不是经过独立验证的错误率保证；门槛在开发观察后加入，评测不称为盲测。

拥有者隔离、用户/助手角色分离、原文 ID、跨会话来源及时间字段继续保留。重排或模型故障返回有标记的回退，不伪造模型判断成功。证据超出交付条数或原话被截断时，不声明充分；原始观察写入不依赖分类成功。

## 实测

相同冻结 12 个开发场景、相同来源记录，每个活跃链路测 36 次串行暖机请求。严格通过要求必需证据齐全、没有额外无关证据、充分性符合预先标签。

| 指标 | 原 Qwen 串行链路 | 新 Qwen 批量与兜底链路 |
| --- | ---: | ---: |
| 完整记忆检索中位耗时 | 1,031 ms | 364 ms |
| P95 耗时 | 1,221 ms | 508 ms |
| 12 场景严格通过 | 5 | 7 |
| 对预标不足场景误判充分 | 0 | 0 |

耗时包含索引、0.6B、4B 和本地到 lab 的 SSH，不含生成回复；不是并发或长历史压测。不同轮次网络/服务器负载有变化，Laya 参考中位也从 433 ms 降到 253 ms，不能把全部耗时降幅严格归因于批量实现。新链路一次相关性 RPC 取代多次 RPC 的变化是明确的。30 次短候选单项判断中位 66.5 ms、P95 91.7 ms。

原来“钢琴教师”原话没进 BM25 候选的语义改写场景，通过近期原话扩展被找回。余下 5 项严格失败主要是字段/跨会话合并漏判、显式未记录时长的事实漏判、实际方法问题混入视频观看等证据；没有通过返回完整候选池冒充模型接受来提高分数。

同一冻结 311 项实际接口对照：

| 指标 | 原单条服务 | 新批量服务及稳定性保护 |
| --- | ---: | ---: |
| 原始标签正确 | 300 | 301 |
| 正确接受 | 300 | 300 |
| 错误接受 | 9 | 8 |
| 弃权 | 2 | 3 |

BF16 在 `qwen-fresh-pair-19-no` 的原始类别有一项变化，两边均弃权。首版未加稳定性保护时错误接受为 10，原始结果保留在 `batch-verification-before-stability.json`，没有隐藏失败。保护主要增加弃权，不能解释成又训练出了更准确的模型。

另冻结 8 个新开发表达：职业语义改写、混合本人/家人、导师给本人打电话、睡觉时间修正、练琴时长冲突、演出票日期/座位、询问家人的宠物、未来意图与已发生事件。严格通过 **7/8**，对两个预标不足场景均未误判充分。混合本人/家人的同一句事实仍被模型漏掉；来源规则保留了该原文，不是规则删除所致。新题也由开发者定义，没有独立人工标签，未据此继续调规则、权重或门槛。
