# 心理知识语料扩充与检索 · 2026-10-14

原有RAG集合包含31个片段，以基础FAQ为主，另有一条已核对来源的NHS CBT简介。本轮没有替换原有数据，增加可重建的公开心理健康语料，并核对实际向量、SQL原文和聊天调用。

## 来源与范围

考察了 [MedQuAD](https://github.com/abachaa/MedQuAD)：包含来自NIH网站的医学问答，采用CC BY 4.0；其中三类MedlinePlus子集的答案因版权已被移除，且它是历史医学问答集，不能直接当作当前心理咨询知识库整体导入。本轮选择较新的 [NIMH官方心理健康资料](https://www.nimh.nih.gov/health/topics)。文本依据 [NIMH公共领域复用政策](https://www.nimh.nih.gov/site-info/policies) 使用，来源逐条保留，不复制图片、不代表NIMH认可本应用。

从33个官方来源页面抽取章节，去除导航、研究招募、药物章节和地区热线内容，并进行精确文本去重，形成202个条目。覆盖焦虑、广泛性焦虑、社交焦虑、惊恐、抑郁、压力、自我照顾、睡眠、心理治疗、创伤、ADHD、双相、进食障碍等主题。它是公众科普语料，不是个体诊断、处方或治疗计划数据库。

英文来源快照保留；为适配中文查询，用当前DeepSeek生成服务进行可恢复的逐段翻译。中文和英文共同保存，标记 `translationReviewStatus=not-human-reviewed`。人工抽查了惊恐障碍、自我照顾、心理治疗三类内容，关键否定和适用范围得到保留；没有进行全量专业审核，不能把自动翻译当成专家审定的中文教材。

## 工程链路

1. 来源域名和路径允许列表限制在NIMH `/health/`；页面结构变化或内容不符合范围时排除，不把网页导航误当知识。
2. 以来源URL和章节名称生成稳定ID。保留来源、许可、语言、版本、章节、抓取/来源审核日期、内容与来源页面SHA256。
3. 内部认证的Java接口先保存MySQL原文和元数据，再向Runtime发送分块任务。向量化失败返回明确的 `indexed=false`，可以通过同一ID重试，不假装已成功。
4. 使用现有本地Ollama `nomic-embed-text` 生成768维向量，写入 `psych-agent-knowledge-v2`。分块预算450 tokens、重叠80；每个片段保留主题/章节索引信息。未下载新模型或训练三个角色。
5. 相同索引版本跳过重新嵌入；改版先写新片段，再清理同一文档旧版本。两次完整重放核对SQL一致且向量数量没有增长，原31个片段保留。
6. 通用科普问题命中已导入主题时，优先在有许可、来源域名匹配的资料中进行向量/BM25融合；未覆盖问题和个人倾诉沿用原集合。主题来自导入元数据，采用有界词项匹配，不额外调用重排模型。已核对的旧NHS CBT条目保留资格。检索指标返回 `sourcePolicy` 和 `scopedCorpusSize`，缓存版本更新为 `hybrid-v4-licensed-topics`。

语料快照及流程说明见 [knowledge目录](../agent-runtime/knowledge/README.md)。CLI提供来源构建、可恢复翻译、SQL/向量导入、幂等重放和中文检索检查。私有凭据不在语料、代码或报告内。
