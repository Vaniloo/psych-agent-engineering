# 回应风格调整 · 2026-10-13

新版 warm_expanded_v1 已接入本地开发 Runtime，仍使用 DeepSeek flash，不改变权重、工具权限、写入流程或检索门槛。

## 调整

将表达风格独立到 psych_agent_runtime/response_style.py，graph._respond 组合风格与已有证据、安全、报告和目标规则。普通个人对话默认适度展开为两到三个短自然段，目标约120—260中文字符；信息少时短一些，不硬凑长度。明确简短要求、问候、希望安静、事实读取和澄清有各自长度策略。

要求围绕用户具体表达承接，不每轮套用“很正常/你已经很棒/我一直陪着你”；不堆砌清单，不把每轮结尾都做成追问。用户只想倾诉时不直接给解决方案；需要建议时给一两个有解释、可选择的方向。部分进展保留完成标准，当前说法仍优先于跨会话记录。

温暖不靠虚构人物、场景、动机或身体反应，不做诊断、夸张赞美或排他承诺。事实读取不为了增加长度而心理分析，知识解释按实际来源展开。原有“不把本轮未找到说成完整历史不存在”等约束保留。
