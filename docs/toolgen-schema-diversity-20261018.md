# 动态工具数据V2：结构扩展与训练预检

本轮完成数据与训练入口扩展，不代表新模型效果提升。旧的失败候选和当前正式模型均未替换。

## 数据规模与覆盖

| 产物 | 保留派生记录 |
| --- | ---: |
| 第一批V2自然输入试验 | 1,584 |
| 新增七个结构域 | 1,557 |
| 首批扩展中通过复核的嵌套域 | 225 |
| 训练用数组域补充 | 225 |
| 合计 | 3,591 |

按工具域隔离：train 1,809、calibration 441、validation 459、test 882；共16域。类别为call_tool 2,007、respond 1,035、clarify 549，保留144组核心成对对照。

这些记录包含工具别名、顺序、结果封装的派生变化。训练器每轮抽取201个逻辑状态，不能称为3,591条独立自然提问。当前适合小规模对照实验，尚不能作为大规模泛化课程。

新增输入包含单个必填参数、三个必填参数、可选参数、嵌套对象和数组。训练部分已覆盖这些结构；留出域使用不同业务和工具标识。可选值缺失不作为必需澄清；只有真正必填项缺失时才构造clarify目标。

## 失败记录与修订

首批扩展仅6域完成生成，54个语义来源帧中47个一致，另有两域生成失败。不能把这份失败批次称为通过。失败主要是漏问原定信息、上下文没有补上真正省略的值、背景附带了歧义，以及数组路径格式错误。

修订显式提供省略参数列表，要求逐项表述查询需求，普通背景不再附带未知信息。第二批7域完成、61/63来源帧原始复核一致；嵌套域的一条缺参问法泄露了输入值，整域隔离。两条数组标注仅缺JSON Pointer开头的斜线，程序将无歧义的`accessions/0`规范为`/accessions/0`，保留原始标注并记录规范化；值、来源、需求与标签均不改。

重放缓存后，七域63帧全部通过；重放没有新增API调用。嵌套域使用首批中原本通过的225条去重记录，其余首批域整域排除。数组训练补充9帧通过。上述比例是教师与源需求契约的一致率，**不是工具模型准确率**，也不能掩盖原始失败。

本轮实际新增139次教师API尝试。生成与复核仍使用同一教师，存在相关偏差；结果只作教师草稿，不宣称人工金标。私钥和教师缓存未进入训练包。

## 新评测与契约

另冻结24题，每题具名、匿名和重排三种表示，共72行。题目由开发助手独立编写，没有使用教师生成模板，覆盖可选项、嵌套/数组、历史来源、成本变化、误导工具名、完整/部分/空/失败/错误对象结果和用户更正。它不是独立人工金标；没有加入训练或校准，也还没有模型效果结果。

V2保留Qwen原LM Head的yes/no logits评分，候选描述和schema是输入，不增加固定工具分类头。新增的路径解析、字段覆盖证明和来源审核仅在离线数据管道使用，没有把这些规则接入在线Agent来替代模型。

`training.toolgen_v2.train_qwen`显式注入V2渲染器和数据加载器，复用原训练器的LoRA和联合损失。V2渲染器会传入带role的history，旧V1入口继续拒绝V2。新入口校验文件哈希、分区、来源争议、去重、结构覆盖和新评测泄漏。实验训练需显式使用`--allow-teacher-drafts`；此标志只允许实验使用，不把草稿标成已人审，也不触发部署。

在agent-runtime目录执行：

```sh
python -m training.toolgen_v2.ground_pilot --catalog expanded --out /data/experiment/pilot --max-calls 100
python -m training.toolgen_v2.curate --source /data/experiment/pilot --destination /data/experiment/curated
python -m training.toolgen_v2.train_qwen --freeze-holdout --holdout /data/experiment/holdout
python -m training.toolgen_v2.train_qwen --preflight-only \
  --data /data/experiment/curated \
  --holdout /data/experiment/holdout --out /data/experiment/preflight
```

目录必须全新；遇到生成或来源分歧不能直接忽略。实际冻结产物按本轮的四个curated目录合并，以上为新实验的入口示例。

## 验证与限制

本地Runtime回归826通过、1项因本机缺Torch跳过。数据预检通过：四个分区非空，训练结构覆盖完整，冻结新题与全部数据分区没有相同查询、工具名或模型输入。

GPU兼容检查通过：lab数据盘内隔离目录，真实AutoTokenizer验证含冻结评测的17,199个候选序列，最长1,491 tokens，无截断；临时BF16 LoRA对五种训练输入结构反向传播并完成一个优化器步，梯度有限、参数实际变化，峰值11,289 MiB。随后丢弃临时适配器，不保存模型，不接入服务。380.7秒包括数据校验和加载，不能作为完整训练吞吐。数值见outputs中的`gpu-smoke/report.json`；它检验训练可执行性，不能代替新模型评测。

已知边界：输入值目前要求字面依据；“二十四”与24等语义归一、布尔输入和空数组输入尚未形成系统课程；结果对象匹配采取精确输入匹配，尚不覆盖可选默认值归一。工具全部为只读合成契约，没有验证真实MCP执行、写入权限和线上任务成功率。下一轮应比较旧失败候选与新候选的冻结评测，不能用来源一致率替代模型收益。
