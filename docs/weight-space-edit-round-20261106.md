# Weight-Space 小幅修改实验 · 2026-11-06

## 范围与假设

在两轮激活定位未发现可靠语义电路后，用户授权先做一轮实际修改。本轮是受控参数敏感性实验，不能称为已定位错误机制的修复。

仅将生命周期 LoRA 的第 23、26 层 MLP（up/gate/down）的 B 因子乘以 0.8 或 1.2；A、基础权重及其他模块不变。分别测试单层与两层组合，共 6 个目标候选；另有原版、全局 0.8 和第 10 层／10+12 层对照，共 12 个方案。

这改变的是整个低秩增量，而非已确认语义方向。激活移植有效不意味着缩放权重有效；结果也可能为负。

## 冻结与评测

- 全部方案在第一次前向前写入 protocol.json。
- 使用完整 validation 选择，不根据测试或已知失败案例调整强度。
- 候选必须增加验证集正确数，且任务宏平均、relevance 正确数不下降，生命周期误写不增加。
- 没有通过候选时仍导出一个诊断副本，明确禁止推广。
- 选择冻结后，仅评估原版、候选、全局对照及匹配层数/强度对照。
- 旧 test/challenge 已在前轮使用，属于重复回归检查，不是全新盲测。
- 验证基础权重与原始 LoRA SHA-256、序列化一致性、重新加载前向一致性。
- 所有远端写入 data 盘；不更改服务，不覆盖正式模型，不训练。

预设层对照 L10×1.2 为 3499/3502、L10+12×1.2 为 3500/3502（仅验证集）。不能据此改选对照或宣称泛化改善；它们没有经过本轮最终回归，也不支持 L23/26 具备特殊修复优势。

主评测 3542 个前向批次、1252.07 秒；挑战回归 126 批次、44.96 秒，共约 21.6 分钟（不含部分前置校验）。没有训练梯度。导出重新加载最大 logit 差为 0。
