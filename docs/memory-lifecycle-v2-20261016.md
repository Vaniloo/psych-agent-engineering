# Memory边界专项第二轮 · 2026-10-16

本轮修正多候选比较的不确定性处理，并做一次独立4B边界专项训练。第一轮报告见 [v1](memory-lifecycle-v1-20261016.md)，正式Memory仍为10月12日adapter。

## 应用侧修正

原旁路在遇到首个被接受的关系后停止比较；如果前面弃权，后面无关系，也可能覆盖前面的不确定结果。现在最多比较3条同账号候选，保留每条目标ID、版本和三项关系判别：

- 任一比较弃权或自相矛盾，转review，后续无关系结果不能将其改为add。
- 多个候选被判断为相关，转review，不任意挑第一条替代。
- 一次预览中模型版本变化或模型调用失败，转review；失败作业计入Runtime指标，原话照常保存。
- 审计幂等加入旁路策略版本 `memory-lifecycle-shadow-v2`；同模型的新策略结果不会被旧策略审计覆盖。

同一v1模型配新保护逻辑的8项合成诊断为5/8动作符合预期，旧逻辑为6/8。差异是音乐偏好的明确更正同时错误命中两个目标，新的逻辑转为review。保护减少了直接选择错误目标的机会，不能将其表述为模型准确率提升。整个过程中没有调用正式事实写入。

## 数据与训练设计

保留v1四分区原始前缀，新增18类边界场景，覆盖共存属性、无关事实、施受关系、第三人称、引用、假设、临时状态和明确更正等。归一化任务输入去重，新事实族按40/20/20/20划分。新增3255训练行，总训练9137行；calibration 3472、validation 3502、test 3644。共享模板仍存在，程序标签不能替代独立人工评测。

冻结挑战为旧311+第一轮生命周期60+新增120，共491行。新增120行在v2评分前冻结，但情境设计参考了v1错误，属于开发回归，不是无偏测试。v1在这120条上107条正确、10条错误接受、4条弃权。

本轮从正式10月12日Memory adapter开始，学习率2e-5，BF16 LoRA r16/alpha32，一轮，微批4×梯度累积4；第一轮从同一个初始adapter开始但学习率3e-5，因此不能把差异全部归因于数据。源码、课程、日志、检查点均在lab的data盘；没有采集真实聊天或调用教师API。

课程、训练源码SHA、评分前门槛与正式/v1 HTTP基线在结果产生前提交并推送为 `31cbe9a`。门槛仅用于开发对照，不自动授权正式替换或记忆写入。见 [实验目录](../agent-runtime/training/experiments/memory-lifecycle-20261016-v2/README.md)。

## 结果

训练与留出评测完成；572次优化，优化循环约744.8秒，报告计时933.5秒（包含后续校准/评测，不包含模型加载与训练前对照），峰值分配8720.3MiB。候选权重SHA与逐任务原生结果见实验目录的training-report。

新增任务原始正确率88.9%→93.9%；这只对应作者编写的开发挑战。来源支持grounded在合并36条挑战中达到36/36，但关系方向、价值判断和替代仍有错误，不能据此开放自动写入。

训练器原生评测使用batch4，与HTTP batch16有2条边界选择不同：一个看诊更正的write_worthy和一个临时心情的duplicate。HTTP中两者都弃权；原生与HTTP的新任务合计均169/180，但60/120子集分配不同。因此不混用两种口径，原生报告保留不改。完整对照和差异见 [comparison.json](../agent-runtime/training/experiments/memory-lifecycle-20261016-v2/comparison.json)。

预先冻结的生命周期比较门槛通过，正式读取回归门槛未通过（relevance少1条正确，多1条错误接受）。决定：**只将v2用于专用合成账号旁路，不替换正式Memory，不启用事实写入**；详见decision.json。

## 实际动作与网关联调

同一8场景、新旁路策略下，v1为5/8、v2为7/8；正式记忆写入均为0，预置本人事实保持不变。v2修复了临时偏好未跳过、新增散步偏好被误判冲突两项。剩余明确更正同时误命中音乐和宠物两个目标，程序转review；这是保护生效，不是模型判断正确。

本机Runtime更新为旁路策略v2，仅允许原先的1个专用合成账号访问候选18101，正式Memory仍使用18096。通过5175前端代理发送一条偏好消息后，消息保存成功，事务outbox触发1条v2模型的add预览，活跃结构化记忆条目仍为0。首次在Runtime重启后过早发起的请求返回服务暂不可用，未算成功；确认健康UP后重试，才得到上述结果。失败记录保留在本会话outputs。

旧v1候选推理进程在验证完成后按PID、模块、检查点和端口核对身份并关闭，保留权重及报告；正式Router/Executor/Memory与重排器未停止。v2候选权重留在data盘，没有发布成正式Release。当前没有本轮训练作业继续运行。

## 后续边界

这一轮有明确收益，暂不继续自动堆训练轮次。下一步应优先补“明确更正但不同主体/属性”的反事实审核样本，并独立核对关系方向、数字与否定。当前挑战已用于开发回归，后续收益还需要新的人工审核多轮样例验证。

原子事实提取、旧索引迁移、正式受控写入、删除传播和等预算的三组记忆方案对照仍未完成；原话索引继续增长，本轮不宣称减少存储或实现完整生命周期。
