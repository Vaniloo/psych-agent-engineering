# Attune Frontend

原生 HTML/CSS/JavaScript 静态应用，无需 Node 构建。采用侧栏、单列对话和底部输入框的布局；保留 Attune 品牌与心理支持功能。

主要能力：

- JWT 登录、退出及 USER/ADMIN 权限视图
- 左下角账号菜单可设置模型API：Base URL、API Key、模型名，支持测试连接、按账号保存及恢复应用默认；密钥不存浏览器本地存储，详见[接入说明](../docs/model-api-settings-20261019.md)
- 新对话欢迎页、起始话题、会话标题搜索与历史恢复
- 新对话随机显示简短问候；仅在初始化和开始新对话时更新，连续两次不重复
- POST SSE 流式回复；Enter 发送，Shift + Enter 换行，输入法组合输入不会误发送
- Markdown 标题、列表、表格、代码与引用；本地 Marked 解析后经 DOMPurify 白名单过滤
- 复制回复、自动滚动和回到最新消息；阅读旧消息时不强制滚动
- 停止接收回复并保留已收到的文字；这不保证服务器推理或记录保存也被取消
- 引用、处理过程与运行指标收纳在对话详情中
- 新对话回复上方显示实际工具调用：调用中、完成、失败、未更新和未确认；展开查看简短结果与耗时
- 新回复下方显示真实记忆处理状态：后台整理、近期索引就绪、长期变更成功、无新增或待确认；点开查看说明
- 目标与行动反馈、陪伴风格、个人报告、帮助资源；管理员保留记忆与知识运维
- 陪伴风格用紧凑列表选择，编辑弹窗只展示名称、人设和对话示例；PNG/JSON导入保留，导出收进次级菜单。开发白名单保持原样
- 个人报告：7/30/90 天的跨对话概要、主要话题、情绪表达分布与时间图；点击柱子查看原话并返回对话
- 桌面侧栏折叠、手机抽屉、键盘焦点管理、深浅主题与减少动画偏好

三个独立角色的权限判断、工具选择和记忆处理仍在后端运行；当前 Router 使用微调 Qwen 4B，Executor 分为 Laya 工具选择与 Qwen 4B 目标判断，Memory 独立使用 Qwen。前端通过 SSE 展示实际结果，不在浏览器复制这些决策。

工具活动使用 `tool_activity` SSE 事件，以 callId 配对开始和结束；最终 capabilityCalls 可补齐未收到的条目，不将规划事件当作已调用。活动跟随本次回复，断线或停止接收只标记结果未确认，不宣称服务器操作被取消。旧历史消息接口没有按消息关联的工具轨迹，因此恢复历史时不推测调用记录；完整已保存运行信息仍在运行指标页查看。

2026-10-19简化：世界书与场景/开场白编辑入口移除，Runtime不再将旧卡的世界书、场景开场白或网络语气参考注入回复，原始卡片传输数据保留以支持历史导出。专门的`search_role_voice`保持关闭，并从工具活动与运行指标的工具列表隐藏；通用`search_web`不受影响。旧的世界书实验文档属于历史设计，不代表当前启用功能。

记忆提示由 `memory-status.js` 驱动。聊天确认保存后，以本轮requestId查询`GET /agent/memory-updates/{requestId}`；Spring先校验当前JWT账号的已保存receipt，再请求内部Runtime状态。后台在原话索引和实验投影完成时记录独立状态，不能以outbox已确认代替长期记忆成功。普通账号显示近期索引状态，只有实际实验变更才显示“记忆已更新”。查询最多10次，处理超过45秒或网络结果未确认时提供只读“重新检查”；切换会话/账号后停止更新，状态接口禁止缓存。旧历史消息缺少requestId映射，因此不补造历史提示。

## 本地运行

在 `frontend` 目录执行：

```bash
python3 -m http.server 5173
```

访问 `http://localhost:5173`。默认 API 为 `http://localhost:8080`，可用 `?apiBaseUrl=http://localhost:8080` 指定。正式 Nginx 环境使用同源 `/api/` 反代 Spring，并关闭 buffering 以实时输出 SSE。

## 静态依赖

`vendor/` 固定保存 Marked 18.1.0 与 DOMPurify 3.4.16。无需 CDN 或联网加载脚本，Docker 镜像同时复制这些文件。`vendor/manifest.json` 记录来源与校验和，许可证随文件附带。

## 个人回顾契约

`GET /reports/overview?days=30&refresh=false` 只整理当前 JWT 用户的表达，由现有本地 LLM 服务生成。服务端最多采样最近 8 段会话，每段最多 30 条用户消息、600 个字符，单条最多 300 字符；界面展示实际覆盖范围与采样提示。缓存位于进程内，原话改变或窗口变化会重新生成；“重新整理”跳过缓存。

概要和主题必须引用本次采样的消息 ID。情绪标注还需要引用真实原话片段，系统过滤无效 ID、未知类别、重复类别与非原文引用，按消息的真实日期计算次数。归类来自 AI，引用校验不能保证分类语义准确。图表表示提及频率，不是心理评分，也不计算活动改善百分比。数据不足或模型不可用时仅保留记录，不生成推测的情绪图。

个人回顾独立于单轮风险扫描。管理员的原有统计收纳在折叠区域中。部署需要同时更新前端与后端；两个查询对应的复合索引已配置在实体中，未使用自动建表的环境需要按项目数据库迁移流程创建索引。
